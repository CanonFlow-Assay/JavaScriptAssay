# JavaScriptAssay 0.1 preview contract

Authority is limited by observed evidence and declared scope. Domain syntax observations are deliberately conservative; a matching identifier may be shadowed, and custom mutators, alias analysis, getters, proxies, prototype effects and indirect calls are not proven safe. const does not establish deep immutability. Freezing and acceptance tests in the specimen are separate runtime evidence.

The policy admits only schemaVersion, domainFiles, boundaryFiles, evidenceFiles and requiredCommands. Domain and boundary sources must be .js, .mjs or .cjs. Source parsing uses TypeScript ScriptKind.JS plus real Node --check commands, never eval. Static relative imports/re-exports in domain must resolve by exact filename into declared domain sources, otherwise scope remains incomplete. Dynamic loading in domain is an observed policy violation. No general bundler or package-resolution claim is made.

verify snapshots every declared source/evidence file, policy, package manifest and lockfile before command execution and compares them afterwards. It records parser/runtime version, evaluator source digest, catalog digest, each exact file hash, command vector, exit/signal and output digest. Evaluator changes during execution invalidate freshness too. These are local integrity bindings, not signed independent attestations. Transient edits that are restored before the final snapshot are outside the detector; run qualification in an isolated checkout for stronger process control. Arbitrary undeclared command dependencies are unassessed.

Any parse/syntax/execution infrastructure error is ToolFailure. Incomplete scope, unknown imports, absent declared inputs, zero required commands, provisional scan or changed observed inputs are Inconclusive. Complete static violations or a real nonzero required command exit are Fail. Only complete verify with zero findings and every required command passed is an authoritative scoped Pass. Config errors are represented by a non-authoritative CLI ToolFailure envelope. No baseline suppression, fixes, releases or automatic equivalence exist.

The assessment wraps the exact original receipt. ReadyForReview is a projection, not human review or release approval. Decision assistance is a separate pure function tested against failure/incompleteness/budget guards. The playground's candidate named integer-equivalent is intentionally unresolved after surviving tests; its name does not grant equivalence.

Receipt JSON keys and finding order are canonical. The static scan is deterministic for unchanged bytes, runtime and evaluator. Executed command output can contain timing or other nondeterministic observations; its digest honestly reflects those bytes. Generated evidence is retained in ignored artifacts/, never relabeled as historical or independently reviewed evidence.

Artifact destinations are checked before required commands run and again before writes. Outputs cannot alias declared inputs, referenced command files, evaluator sources, policy/lock files or one another, including symbolic links and hard links. These are local filesystem checks, not a defense against hostile concurrent filesystem changes. The reservation adapter accepts own data properties; accessors and descriptor failures return InvalidInput. Its command retains a minimum of14 actual tests with zero failed, cancelled or skipped cases.
